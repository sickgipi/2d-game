# 🗡️ Zelda-Inspired 2D Game

A personal project created to learn and experiment with **Python and Pygame**, inspired by the classic *The Legend of Zelda* games.

## 🎮 About the Project

This project is part of my journey to learn game development using Python and Pygame. I'm building a 2D adventure game inspired by Zelda, experimenting with game mechanics, player movement, collisions, and more.

The main goal is to improve my programming skills while having fun creating a game from scratch.

## 🚀 Goals

- [x] Set up the project with Python and Pygame
- [ ] Implement player movement
- [ ] Add collision detection
- [ ] Create a tile-based map
- [ ] Add animations and sprites
- [ ] Implement enemies and combat mechanics
- [ ] Add items and collectibles
- [ ] Create different areas to explore

## 🛠️ Built With

- **Python** — Programming language
- **Pygame** — Library for game development

## 📚 What I'm Learning

Through this project, I'm exploring:

- Object-oriented programming in Python
- Game loops and event handling
- Sprite management and animations
- Collision detection
- Game physics and movement
- Level design and tile maps
